# マイボイス — 声クローン音声生成

自分の声を登録して、入力した文章をその声で読み上げるブラウザアプリです。ElevenLabs API を使います。

## 使い方

1. [ElevenLabs](https://elevenlabs.io/) で API キーを作成する（声のクローンは有料プランが必要）
2. アプリを開いて API キーを入力し、保存する
3. 30秒〜1分ほど声を録音（または音声ファイルを選択）して登録する
4. 文章を入力して「音声を生成」を押す。MP3 の保存・共有ができます

## 注意

- API キーは端末のブラウザ内（localStorage）にだけ保存されます。このリポジトリには絶対に書き込まないでください。
- 登録するのは自分の声、または本人から明確な同意を得た声だけにしてください。
