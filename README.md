# マイボイス — 音声生成

入力した文章を、ElevenLabs の声で読み上げて MP3 にするブラウザアプリです。

https://shinopipi.github.io/voice-clone/

## 使い方

1. [ElevenLabs](https://elevenlabs.io/) で API キーを作成する（無料プランで使えます）
2. アプリを開いて API キーを入力し、保存する
3. 声を選んで「試聴」で確認し、文章を入力して「音声を生成」を押す
4. MP3 の保存・共有ができます

## 注意

- API キーは端末のブラウザ内（localStorage）にだけ保存されます。このリポジトリには絶対に書き込まないでください。
- 無料プランは非商用利用のみで、ElevenLabs のクレジット表記が必要です。
